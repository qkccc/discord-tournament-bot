
# 📘 Apeiron\_bot プロジェクト概要・仕様書

## 1\. プロジェクト概要

Discordサーバー内での大会運営、Shadowverseの戦績管理、音楽再生、およびコミュニティ活性化を目的とした多機能Bot。

  * **言語:** Python 3.10+
  * **フレームワーク:** discord.py
  * **データベース:** SQLite (`aiosqlite` / `sqlite3`)
  * **主要ライブラリ:** `yt-dlp` (音楽), `yomitoku` (OCR), `google-generativeai` (Gemini), `pandas` (集計), `opencv-python` (画像処理)

-----

## 3\. 機能詳細

### ⚔️ Shadowverse 戦績・デッキ管理

Shadowverseの対戦記録やデッキを管理する中核機能です。

  * **戦績記録:**
      * **手動登録:** パネルのボタン操作で1戦ずつ詳細に記録。
      * **リプレイ登録 (`/replay`):** ゲーム内のリプレイ一覧のスクリーンショットをOCR解析し、一括で戦績を登録。
      * [cite\_start]**右クリック登録 (Apps):** メッセージ上の画像を右クリック（長押し）して「戦績画像を読み取る」で登録可能 [cite: 5]。
  * **分析 (`/stats`):**
      * 「本日」「今月」「全期間」などの期間指定や、クラス別での勝率・対面勝率を集計して表示。
  * **デッキ管理:**
      * デッキのQRコード画像をアップロードして登録。
      * `!deck_panel_user` で登録・確認・削除が可能。
  * **実装の特徴:**
      * **OCR:** `yomitoku` と `OpenCV` を併用し、高精度な文字認識を実現。
      * **非同期処理:** データベース書き込みは `aiosqlite` で非同期化され、Botの動作を阻害しない。

### 🏆 イベント・大会運営

サーバー内での大会をスムーズに進行させるための機能群です。

  * **スイスドロー / シングルエリミネーション:**
      * `!募集` コマンドで参加者を募り、ボタン操作で大会形式を選択。
      * 対戦カードの自動生成と通知。
      * 勝者によるボタン報告で自動進行。
      * 大会終了時、結果を履歴テーブルに保存。
  * **チーム対抗総当たり戦 (`RoundRobin`):**
      * 5人までのチームを作成し、チーム単位での総当たり戦を実施。
      * [cite\_start]**承認フロー:** 対戦結果の報告時、対戦相手チームによる「承認」アクションを経て結果が確定 [cite: 5]。
      * **結果通知:** 承認された試合結果を指定チャンネルへ自動通知。
      * **優勝表示:** 大会終了時、優勝チームのメンバー一覧を表示。
      * 専用ロールの自動付与・剥奪機能。
  * **チーム分け:**
      * 参加者を「リーダー指名制」または「指定チーム数」でランダムにチーム分け。

### 🎵 音声・通話機能

  * **音楽再生:**
      * YouTubeのURLまたは検索ワードから音楽を再生 (`!play`)。
      * `yt-dlp` と `ffmpeg` を使用。
  * **通話ログ (VoiceLogger):**
      * ボイスチャンネルへの入退室を記録。
      * 通話開始時にテキストチャンネルへ通知。
      * **定例通知:** 毎週土曜日13:05(UTC)に、通話に参加していない特定ロールのメンバーへメンション通知。

### 🛠️ システム・ユーティリティ

  * **自動Cog読み込み:**
      * [cite\_start]`cogs` フォルダ内のファイルを自動的に走査し、Bot起動時にロードします。ファイルを追加するだけで機能拡張が可能 [cite: 5]。
  * **ロギング:**
      * [cite\_start]エラーや動作ログを `bot.log` に自動記録（ローテーション対応）し、トラブルシューティングを容易化 [cite: 5]。
  * **Gemini AIチャット:**
      * BotへのメンションまたはリプライでGoogle Geminiと会話可能。
  * **ルームマッチ募集:**
      * パネルのボタンを押すだけで、`@everyone` 付きのルムマ募集メッセージを送信。

## 4\. データベース設計

現在、データベースは以下の2つに整理されています。

| | `sv_decks` | 登録されたデッキURL |
| | `sv_user_settings` | 通知チャンネル設定 |
| **イベント(共通)**| `event_settings` | [cite\_start]大会設定（通知chなど）[cite: 24] |
| | `event_players` | [cite\_start]大会参加者情報 [cite: 24] |
| | `event_recruitments` | [cite\_start]募集セッション情報 [cite: 24] |
| | `event_participants` | [cite\_start]募集中参加者リスト [cite: 24] |
| **スイスドロー** | `swiss_tournaments`| [cite\_start]大会進行状況 [cite: 24] |
| | `swiss_pairings` | [cite\_start]現在のペアリング [cite: 24] |
| | `swiss_results` | [cite\_start]試合結果 [cite: 24] |
| **トーナメント** | `se_tournaments` | トーナメント進行状況 |
| | `se_matches` | マッチ情報 |
| **チーム総当たり**| `rr_teams` | チーム情報 |
| | `rr_players` | チームメンバー情報 |
| | `rr_tournaments` | 大会進行状況 |

### 2\. `data/sv_cards.db` (SQLite)

  * **用途:** Shadowverseのカードデータ（名前、コスト、効果テキストなど）を格納。
  * **特徴:** ユーザーデータとは独立しており、カード検索コマンド (`/card`) で使用。
