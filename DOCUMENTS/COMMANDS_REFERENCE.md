
# コマンド・UI・メニュー一覧

このファイルは、Apeiron Botで実装されている全コマンド・パネルボタン・右クリックメニュー等の使い方をまとめたリファレンスです。

---

## 1. Shadowverse関連

### パネルUIボタン
- **手動登録** … ボタン押下で戦績を手動入力
- **戦績表示** … 期間・クラス指定でサマリー表示
- **直近履歴** … 件数指定で最新戦績を表示
- **通知チャンネル設定** … 通知先チャンネルを選択
- **全データ削除** … 全戦績データを削除（確認ダイアログあり）

### コマンド
- `/panel` … Shadowverseパネルを設置
- `/record` … ボタン操作で戦績を手動登録
- `/replay <画像>` … リプレイ画像から戦績登録
- `/stats [期間] [クラス]` … 戦績サマリー表示
- `/history [件数]` … 直近履歴表示
- `!svパネル設定` … 管理者用: パネル設置
- `!svchannel` … 通知チャンネル設定/確認/解除

### 右クリックメニュー
- **戦績画像を読み取る** … メッセージ画像から戦績登録

---

## 2. 通話・定例通知・サブアカウント

### コマンド
- `!定例通知スキップ` … 管理者用: 今週の定例通知をスキップ
- `!定例通知確認` … 管理者用: 定例通知の状態確認
- `!メンション対象確認` … 管理者用: 今週通知対象の一覧表示
- `!通話通知設定 <#チャンネル>` … 管理者用: 通話通知チャンネル設定
- `!設定確認` … 管理者用: 現在の設定確認
- `!サブ垢登録 <main_id> <sub_id>` … 管理者用: サブアカウント登録
- `!サブ垢削除 <sub_id>` … 管理者用: サブアカウント削除
- `!サブ垢一覧` … サブアカウント一覧表示

---

## 3. ルームマッチ募集

### コマンド
- `!ルムマ募集パネル設置` … 管理者用: ルームマッチ募集パネル設置

### パネルUIボタン
- **ルムマ募集** … ボタン押下で@everyone付き募集メッセージ送信

---

## 4. 音楽再生

### コマンド
- `!play <URL/キーワード>` … YouTube等から音楽を再生
- `!skip` … 再生中の曲をスキップ
- `!stop` … 再生を停止しキューをクリア
- `!pause` … 一時停止
- `!resume` … 再開
- `!queue` … 現在のキューを表示

---

## 5. Gemini AIチャット

### 使い方
- Botへのメンション、またはリプライでAIチャットが可能
- 例: `@ApeironBot 今日の天気は？`

---

## 6. 大会・イベント管理

### コマンド
- `!募集` … 大会参加者募集パネル設置
- `!大会開始` … 大会を開始
- `!対戦結果 <勝者ID> <敗者ID>` … 試合結果を登録
- `!大会終了` … 大会を終了し履歴保存
- `!チーム分け` … チーム分けパネル設置
- `!チーム戦開始` … チーム対抗戦を開始
- `!承認 <試合ID>` … チーム戦の結果承認
- `!大会履歴` … 過去大会の履歴表示

### パネルUI・ボタン
- **参加** … 募集パネルから参加登録
- **対戦カード表示** … 現在の対戦カードを表示
- **勝者報告** … 勝者がボタンで結果報告
- **承認** … 対戦相手が結果を承認

---

## 使い方例

- `/panel` … Shadowverseパネルを設置し、各種ボタンから操作
- `!サブ垢登録 123456789 987654321` … ユーザーIDでサブアカウント登録
- `!ルムマ募集パネル設置` … ルームマッチ募集パネルを設置
- `!play https://youtu.be/xxxx` … 音楽再生
- `@ApeironBot おすすめのデッキ教えて` … AIチャット
- `!募集` … 大会募集パネル設置

---

※管理者専用コマンドは権限が必要です。パネルUIはボタン操作で直感的に利用できます。
