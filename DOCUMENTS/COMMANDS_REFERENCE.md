
# コマンド・UI・メニュー一覧

このファイルは、Apeiron Botで実装されている全コマンド・パネルボタン・右クリックメニュー等の使い方をまとめたリファレンスです。

---

## 1. Shadowverse関連

### パネルUIボタン
- **戦績表示** … 期間（今日/昨日/一週間/今期(設定日~)/全期間）・クラス指定でサマリー表示
- **直近履歴** … 件数指定で最新戦績を表示
- **手動登録** … ボタン押下で戦績を手動入力

### コマンド
- `/record` … ボタン操作で戦績を手動登録
- `/replay <画像>` … リプレイ画像から戦績登録
- `/stats [期間] [クラス]` … 戦績サマリー表示（期間: 今日/昨日/一週間/今期(設定日~)/全期間）
- `/history [件数]` … 直近履歴表示
- `/deletestats [期間] [クラス]` … 自分の戦績データを削除（期間・クラス省略時は全削除、指定時は該当分のみ削除。件数を表示したうえで確認ダイアログあり）
- `!season_start [YYYY-MM-DD]` … 今期開始日を確認/変更（変更はサーバー管理権限が必要）
- `!svパネル設置` … 管理者用: パネル設置
- `!sv通知チャンネル設定 <@メンバー> <#チャンネル>` … 管理者用: 指定メンバーの通知チャンネルを設定
- `!sv通知チャンネル一覧` … 管理者用: 通知チャンネルの登録状況を一覧表示
- `!svchannel view` / `!svchannel clear` … 自分の通知チャンネルの確認/解除
- `!svstats確認` … 管理者用: チーム全体の匿名集計を試算（サイトへは push しない）
- `!svstats公開` … 管理者用: 集計を今すぐ生成し apeiron-site へ push（通常は毎日05:15に自動実行）

### 右クリックメニュー
- **戦績画像を読み取る** … メッセージ画像から戦績登録

- `!サブ垢削除 <sub_id>` … 管理者用: サブアカウント削除

## 4. 音楽再生

## 6. 大会・イベント管理

### コマンド
- `!募集` … 参加者募集パネルを設置（参加者は👍リアクションで参加登録）
- `!sd設定メイン` … 管理者用: 大会アナウンス用チャンネルを設定
- `!sd設定対戦` … 管理者用: 対戦カード送信用チャンネルを設定（チーム総当たり戦の対戦カードもここに送信されます）
- `!追加 [名前]` / `!削除 [人数]` … 管理者用: 募集中のダミー参加者を追加/削除
- `!中止` … 管理者用: 進行中の募集や大会を強制中止
- `!トーナメント再送` … 管理者用: 進行中トーナメントの対戦カードを再送
- `!ヘルプ3` (`!sdヘルプ`) … 大会・チーム分け機能の詳細ヘルプ

### 募集パネルのボタン
- **スイスドロー** / **トーナメント** … 参加者確定後、大会形式を選んで開始
- **チーム分け** … リーダー制 or 指定チーム数でランダムにチーム分け
  - 分け結果メッセージの **「⚔️ この分け方で総当たり戦を開始」** ボタン→チーム名を確認・変更→「開始」で、そのままチーム総当たり戦（下記7.）へシームレスに移行できます
- **募集を中止** … 募集自体を取り消し

### 大会進行中のボタン
- **勝者報告** … 勝者が自分の勝利ボタンを押して結果を報告（自動で次の対戦へ進行）

## 7. チーム総当たり戦（RoundRobin）

「6. 大会・イベント管理」の **チーム分け** 結果から「⚔️ この分け方で総当たり戦を開始」ボタンで始めるか、以下のコマンドで手動登録して始めます。結果発表・対戦表は `!sd設定メイン`、対戦カード・結果報告は `!sd設定対戦` で設定したチャンネルに送信されます（大会機能と共通、スイスドローと同じ役割分担）。

### コマンド
- `!チーム登録 <チーム名> <メンバー...>` … チームを新規登録（人数上限なし、サーバーにいないメンバーはダミー扱い）
- `!チームメンバー追加 <チーム名> <メンバー...>` … 既存チームにメンバーを追加
- `!チーム取消 <チーム名>` … チームの登録を取り消し
- `!総当たりパネル` … 管理者用: チーム登録用パネルを設置
- `!総当たり開始 [random/fixed]` … 登録済みチームで総当たり戦を開始（打順指定可）
- `!次節` … 次の節（ラウンド）を開始
- `!順位` … 現在の順位を表示
- `!総当たり中止` … 管理者用: 進行中の総当たり戦・登録情報・関連ロールをすべてリセット
- `!ヘルプ5` … チーム総当たり戦の詳細ヘルプ

## 使い方例

- `!svパネル設置` … Shadowverseパネルを設置し、各種ボタンから操作
- `!sv通知チャンネル設定 @taro #taro-個人ch` … taroさんの通知先を設定
- `!サブ垢登録 123456789 987654321` … ユーザーIDでサブアカウント登録
- `!ルムマ募集パネル設置` … ルームマッチ募集パネルを設置
- `!play https://youtu.be/xxxx` … 音楽再生
- `@ApeironBot おすすめのデッキ教えて` … AIチャット
- `!募集` … 大会募集パネル設置

※管理者専用コマンドは権限が必要です。パネルUIはボタン操作で直感的に利用できます。
